# Progress

Progress indicators show how far a task has progressed, providing visual feedback to users about ongoing processes.

<ComponentPreview>
<div className="flex flex-col gap-4 w-full">
  <Progress value={25} aria-label="Upload progress" />
  <Progress value={50} aria-label="Upload progress" />
  <Progress value={75} aria-label="Upload progress" />
  <Progress value={100} aria-label="Upload progress" />
</div>
</ComponentPreview>

## Usage

```tsx
import { Progress } from '@e-infra/design-system'

<Progress value={33} aria-label="Upload progress" />
<Progress value={75} max={100} aria-label="Upload progress" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| value | number | - | Current progress value (0-100) |
| max | number | `100` | Maximum value for progress calculation |
| aria-label | string | - | Accessible name for the progress bar (required unless `aria-labelledby` is set) |
| className | string | - | Additional CSS classes |
| ...props | React.ComponentProps | - | Radix UI Progress props |

## Examples

| Value | Visual |
|-------|--------|
| 0% | Empty progress bar |
| 25% | Quarter filled |
| 50% | Half filled |
| 75% | Three-quarters filled |
| 100% | Fully filled |
